LibraSort – Library Book Arrangement Optimizer

About the Project

LibraSort is a Design and Analysis of Algorithms (DAA) project that helps libraries arrange and locate frequently requested books efficiently.

Problem Statement

Arranging books based on demand, shelf capacity, and search time can be challenging. LibraSort aims to improve book organization and make frequently requested books easier to locate.

Objectives

- Organize books efficiently.
- Consider book demand and shelf capacity.
- Reduce book search time.
- Improve library book management.

Technologies Used

- React
- TypeScript
- Vite
- Node.js
- Express.js
- PostgreSQL
- Drizzle ORM
- Clerk Authentication

Project Type

Design and Analysis of Algorithms (DAA) Project
